# RAG-vivarium

Учебный RAG-проект по аквариумистике и террариумистике. Сейчас реализованы парсинг источников и чистка текстов. Следующие этапы: чанкинг, поиск и генерация ответов со ссылками на источники.

## Подготовка

Выберите интерпретатор проекта в PyCharm и выполняйте команды из корня проекта в Python-окружении:

```bash
python -m pip install -r requirements.txt
```

При первом запуске скопируйте `.env.example` в `.env` и заполните настройки.

Извлечение текста из DjVu требует установки программ DjVuLibre и Tesseract с русским и английским языками.

## Парсинг

### Книги

В корпус вошли шесть книг по аквариумистике и содержанию черепах. Исходные PDF и DjVu хранятся в `data/books/source/`. Код находится в `src/books/extract.py`: из PDF извлекается текстовый слой через PyMuPDF, страницы DjVu преобразуются в изображения через программу DjVuLibre и распознаются Tesseract с русским и английским языками.

Запуск: `python -m src.books.extract`. Результаты сохраняются в `data/books/raw/`: отдельный JSONL для каждой книги, одна строка — одна страница с полями `book_id`, `page`, `method`, `text`. На этом этапе `page` — номер страницы в исходном файле. Книги, для которых JSONL уже существует в `raw`, пропускаются.

## Чистка

### Книги

Код находится в `src/books/clean.py`. Общие правила убирают водяные знаки, колонтитулы, печатные номера из текста и служебные страницы. Нормализуются пробелы, HTML-коды и лишние символы, склеиваются переносы слов и строки абзацев. Повторяющиеся ошибки OCR исправляются небольшим словарем. Сохраняются необходимая пунктуация, регистр и стоп-слова. Команда `python -m src.books.clean clean` сохраняет результат в `auto_clean`. Пустые записи удаляются, пропуски в нумерации сохраняются.

После автоматического этапа тексты дополнительно исправлялись вручную, обзор оставшихся ошибок выполнен ИИ. Восстановлены порядок фрагментов и индексы формул, убраны оставшиеся подписи рисунков и нечитаемые табличные фрагменты, исправлены поврежденные слова и разрывы между страницами. Итог: **6 JSONL, 1049 непустых записей в `data/books/clean/`** для чанкинга. Одна строка JSONL — одна непустая страница с полями `book_id`, `page`, `method`, `text`. Авторы, названия и имена исходных файлов находятся в `src/books/books_catalog.json`; ключи каталога совпадают со значениями `book_id`.
